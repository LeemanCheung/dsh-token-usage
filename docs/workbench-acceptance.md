# 原始路线图验收映射 — 0.5.0

此表映射本会话 A–I 计划的具体行为，不以页面名称或测试数量代替需求覆盖。正式结果以对应提交的 CI 日志为准。

| 原计划 | 实现入口 | 验收覆盖 |
|---|---|---|
| A 无模型体检 | diagnostics.ts、snapshot.ts、reporting.ts、App.tsx | scope/action、规则版本、节点证据、时间/路由缺口、项目/金额预算压力；无 LLM 路径；离线缓存 |
| B 价格引擎 | prices.ts、price-history.ts、schema.ts、PriceHistory | 精确路由/币种/有效期、空白/零区分、分时/阶梯不可用处理；人工来源核对、修订指纹、变更历史、差异预览、回滚及淘汰披露 |
| C 辅助账本 | host.ts、ObservablePanel | 累计替换、多调用累计、未知/失败/取消、持久 ID 预约、重连/重启/清空后去重；一致窗口合计与未观测范围 |
| D 变化归因 | insights.ts、cost-attribution.ts | Token 正负增量/零基期/残差；双基准参考金额按用量→缓存结构→费率分解并守恒，不冒充账单 |
| E 用量收据 | NodeExplorer、reporting.ts | 节点条宽、键盘点击证据、四类桶/调用类别/路由分视图、分页口径、有符号残差、默认脱敏导出 |
| F 项目预算 | Projects、projectTotals、rollingMoney | 唯一主项目、多标签不重复、未分组保留、删除不删会话、滚动日期和金额覆盖状态 |
| G 优化实验 | Experiments、ExperimentDetails | 人工标签/验收、任务条件完整展示、配对/样本数/方差、请求与重试分母、旧数据未知、重复快照限制、失败费用入分子 |
| H 情景与时钟 | LongScenario、scenarios.ts | 缓存迁移守恒、跨版本/时段/时区/DST、未知计费时点上下界、并排基线候选、七天限额；不调度任务 |
| I 周报与联动 | weekly.ts、summary-bridge.ts | 双方人工验收的配对成果、重试减少量和负值、脱敏预览/导出、v1兼容/v2预算及采样、默认关闭、Host复核授权 |
| 工程与验证 | selectors/usage.ts、CI、compatibility.yml | 旧页面兼容导出、独立纯聚合、固定工具链门槛、额外兼容性通道、中文/英文/窄屏/键盘、确定性构建与包白名单 |

## 明确的验收边界

自动测试采用合成事件和模型传输；浏览器实际运行工作台 React、Host RPC 与文件持久化。没有声称已在用户机器部署、使用真实账户发起付费调用或核对提供方账单。额外上游通道的实测成功/失败是兼容信号，不推导全部 semver 范围均支持。

同一价卡中叠加分时和上下文阶梯仍明确拒绝；没有请求上下文、缓存写入类别或计费时点时不得套价。日聚合不能重建逐分钟用量，因此区间场景保守输出范围，而非构造历史小时记录。

实际鲸鱼/城市等外部插件的视觉适配不是本仓库交付的一部分；此处交付可选数字协议及接入示例，不在其他仓库加入硬依赖。原计划排除的自动路由/断路器、人员画像、虚假碳排或模型能力排行榜仍不做。
